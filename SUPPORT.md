# Support

For usage questions, bugs, or feature requests, open a GitHub issue:

https://github.com/marvinvista/things-cli/issues

Before opening an issue, please include:

- macOS version.
- Things version.
- Install method (`pipx`, local clone, or development venv).
- The command you ran.
- Whether `things diagnose` succeeds.
- Sanitized output with private todo names, notes, tags, and project names removed.

Do not paste private Things exports or audit logs into public issues.
